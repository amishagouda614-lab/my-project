# Viedo Sumeriuzation

## Project Objective

The objective of this project is to analyze and summarize video-related data and generate useful insights.

## Project Description

This project involves data collection, data cleaning, data analysis, SQL queries, and data visualization using Power BI.

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Plotly
- SQL
- Power BI
- Jupyter Notebook
- Git
- GitHub

## Dataset Information

The dataset used for this project will be stored in the Dataset folder.

Raw datasets will be stored in:

Dataset/Raw_Data/

Cleaned datasets will be stored in:
